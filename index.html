단계별 필수 키워드 & 판정 기준

1. 리드 스크류
  • 처짐량: ≤ 0 mm (무전원)
  • 하중: 100g 승강
  • 리미트: 0건 오작동 정지
  • 목적: 기구 기초 동작 확인
2. 소프트웨어
  • 인식률: ≥ 95% 마커 검출
  • 도킹 제어: 중심/각도 보정
  • FPS: 웹캠 실시간성
  • 목적: 자율주행 코어 알고리즘
3. 시뮬레이션
  • 완주율: 100% 가상 도킹
  • FSM: 접근➔도킹➔승강➔복귀
  • 예외 처리: 마커 유실 시 정지
  • 목적: SW 로직 사전 검증
4. 지게차 실물
  • 연동: SW 명령 즉각 반응
  • 도킹: 1회 완주 픽업 성공
